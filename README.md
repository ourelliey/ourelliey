## About Me

Hello! I'm **Aurellia Nabila**, a Computer Engineering undergraduate student at Universitas Jenderal Soedirman, Indonesia.

I'm passionate about exploring technology, building practical solutions, and turning ideas into meaningful projects.

My interests revolve around software development and hardware integration, especially:

- **Web Development** - Building responsive and functional web applications.
- **Internet of Things** - Exploring connected devices and real-time monitoring systems.
- **Embedded Systems** - Working with microcontrollers, sensors, and hardware programming.
- **Software Engineering** - Learning programming concepts, system design, and problem-solving.

I enjoy learning through hands-on projects, collaborating with others, and continuously improving my technical skills.

Here are some projects I've worked on during my learning journey.

### 1. Donation Management Website

**Technologies:** Laravel · React · PHP · MySQL

A collaborative web development project focused on managing donation-related information, including donated items, categories, donors, and recipients.

[View Repository](https://github.com/ourelliey/Kelompok2-ShiftD-ResponsiPemweb2Laravel)

### 2. IoT & Sensor Monitoring

**Technologies:** Arduino · ESP32 · MQTT · Python

Exploring microcontroller programming, sensor data collection, MQTT communication, and real-time monitoring.

[View Repository](https://github.com/ourelliey/H1H024066_Praktikum-IoT)

### 3. Smart Pajama Conveyor System

**Technologies:** ESP32 · Arduino Uno · IR Sensor · PID Control · Web Development

An IoT-based automated pajama conveyor system designed to detect, count, and identify pajama types and sizes. The system integrates microcontrollers, sensors, and motor speed control to support an automated garment handling process.

**My Contribution:** Contributed to the system's calculation and control logic, including PID-based conveyor speed control and rack capacity calculations, as well as web interface development and hardware integration.

[View Project Repository](https://github.com/fikririzqinfaizun/TugasBesar-InternetOfThings-Kelompok6)

### 4. PokéCare – Ekans Training System

**Technologies:** PHP · Object-Oriented Programming

A programming project developed as part of my Object-Oriented Programming coursework, focusing on structured code and object-oriented concepts.

[View Repository](https://github.com/ourelliey/Aurellia-Nabila-Rahma-Putri_H1H024066_ResponsiPBO25)

### 5. Embedded Systems & Microcontroller Projects

**Technologies:** C++ · Arduino · Microcontrollers

A collection of practical exercises and projects involving embedded programming, communication protocols, and microcontroller implementation.
